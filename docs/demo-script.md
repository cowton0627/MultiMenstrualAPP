# 羽時 Demo 錄影腳本（60–90 秒）

## 錄影前

- 使用直向 iPhone，開啟「勿擾模式」，關閉通知預覽。
- 在設定載入展示資料，再回到首頁。
- 清除狀態列不必要的個資；保持充足電量與穩定畫面。
- 第一版先錄純操作畫面，確認節奏後再補旁白或字幕。

## 分鏡

### 0–8 秒：產品定位

畫面：App icon → Splash → 首頁人物列表。

旁白：「羽時是一款隱私優先的多人經期管理 App，讓同一台裝置可以管理多位人物，資料完全離線保存。」

### 8–25 秒：人物與月曆

畫面：點入「小羽」，上下滑動月曆，停在已有紀錄與預測的月份。

旁白：「每位人物有自己的代表色、週期紀錄與預測視窗。月曆同時呈現實際紀錄和下一次可能日期。」

### 25–42 秒：新增紀錄

畫面：選擇日期 → 新增紀錄 → 示範尚未結束狀態與備註 → 儲存。

旁白：「紀錄可以持續編輯，也支援尚未結束的經期與簡短備註。」

### 42–58 秒：跨人物總覽

畫面：切換總覽，展示人物數、紀錄數、下一次預測與最近紀錄。

旁白：「總覽將多位人物的重要資訊集中呈現，適合家庭或照護情境快速掌握。」

### 58–72 秒：隱私與備份

畫面：設定 → 匯出資料，再帶到作品展示區塊但不要真的清除。

旁白：「App 不含登入、廣告或分析 SDK；資料保留在裝置，也能透過有版本控制的 JSON 自主備份。」

### 72–85 秒：工程收尾

畫面：回到首頁；後製疊上 SwiftUI、MVVM、Core Data、69 tests。

旁白：「專案採 SwiftUI、MVVM、Repository 與 Core Data，並以 69 個單元測試保護領域邏輯和資料流程。」

## 輸出建議

- 主版本：1080 × 1920、H.264、60–90 秒、有中文字幕。
- 另輸出 15–20 秒無聲精華版，方便嵌入作品集首頁。
- README 建議使用 YouTube unlisted 或 Vimeo 連結；GIF 只保留一段最關鍵互動，避免 repo 過大。
